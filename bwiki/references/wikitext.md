# Wikitext 编写规则

## 1. 写法优先级

1. **Wikitext**：正文、标题、列表、表格、链接、分类、引用、模板调用。
2. **模板 / 模块**：重复结构用模板封装；复杂逻辑用 Lua 模块生成 wikitext。
3. **HTML**：仅当 wikitext 无法表达时使用，且只使用 Sanitizer 允许的标签。
4. **CSS**：样式放 `MediaWiki:Common.css`、`#css` 或 `<bstyle>`，通过 class 关联。

不要用 HTML 表格替代 wikitext 表格，不要用 `<br>` 或空 `<div>` 堆版式，不要把整段内容包进 `<div>` 只为了加样式。

## 2. 页面结构

```
（可选：维护提示模板）
导语段落

== 一级章节 ==
正文

=== 二级章节 ===
正文

== 参考资料 ==
<references/>

[[分类:示例]]
```

- 标题层级从 `==` 开始，逐级递增，不跳级。
- 标题文字不加链接、不加粗体标记。
- 目录由系统生成；需要调整位置用 `__TOC__`。
- 分类写在页面末尾（位置不影响归属，只影响可读性）。

## 3. 段落与换行

| 写法 | 效果 |
|---|---|
| 单换行 | 渲染为空格，不换行 |
| 空行 | 分段；同时结束列表与表格 |
| 行首空格 | 该行作为 `<pre>` 输出 |
| `<br>` | 强制换行（仅用于诗句、地址等必要场景） |

段落之间用一个空行；不要用连续空行控制间距。

## 4. 列表

```
* 一级
** 二级
*# 二级有序
# 有序
#* 有序下的无序
; 术语
: 定义
```

- 符号必须位于行首，可混用（`*#`、`#*`）。
- 列表项之间不留空行；空行会结束列表。
- 定义列表也可写在同一行：`; 术语 : 定义`。
- 列表项内需要多段时，用 `<br>` 或续行缩进，不要插入空行。

## 5. 强调与行内格式

| 效果 | 写法 |
|---|---|
| 斜体 | `''文字''` |
| 粗体 | `'''文字'''` |
| 粗斜体 | `'''''文字'''''` |
| 等宽 | `<code>文字</code>` |
| 删除线 | `<s>文字</s>` |
| 上标 / 下标 | `<sup>2</sup>` / `<sub>2</sub>` |
| 小字 | `<small>文字</small>` |

行内格式优先用 wikitext 标记，不用 `<b>` / `<i>`。

## 6. 表格

```
{| class="wikitable"
|+ 表格标题
|-
! scope="col" | 列1 !! scope="col" | 列2
|-
| 单元格1 || 单元格2
|-
| colspan="2" | 跨两列
|-
| rowspan="2" | 跨两行 || 单元格
|-
| 单元格
|}
```

规则：

- `{|`、`|-`、`|}`、`!`、`|`、`|+` 必须位于行首。
- 同行单元格用 `||`（数据行）或 `!!`（表头行）分隔。
- 单元格属性写作 `| 属性 | 内容`，如 `| style="width:30%" | 内容`。
- 行/列合并用 `rowspan` / `colspan`。
- 表头建议加 `scope="col"` 或 `scope="row"`。
- `class="wikitable"` 为标准样式；`sortable` 需站点启用 Tablesorter。
- 单元格内需要字面竖线时用 `<nowiki>|</nowiki>`（`{{!}}` 依赖站点是否有该模板）。
- 表格前后各留一个空行；表格内部不留空行。

## 7. 链接

| 类型 | 写法 | 说明 |
|---|---|---|
| 内链 | `[[页面]]` | 不存在时为红链 |
| 带文字 | `[[页面\|显示文字]]` | 竖线分隔目标与文字 |
| 章节 | `[[页面#章节]]`、`[[#章节]]` | 锚点按标题文字生成 |
| 分类 | `[[分类:名称]]` | 加入分类 |
| 分类链接 | `[[:分类:名称]]` | 前导冒号，仅显示链接 |
| 文件 | `[[文件:名称.png]]` | 嵌入文件 |
| 文件链接 | `[[:文件:名称.png]]` | 只链接不嵌入 |
| 外链 | `[https://example.com 文字]` | 无文字时自动编号 |
| 裸链接 | `https://example.com` | 自动识别 |

限制：

- 跨 wiki 链接已禁用，`[[w:页面]]` 之类不生效。
- 非 B 站域名的外链会被加上 `linkfilter` 前缀；URL 中 `&`、`#` 之后的内容可能被截断，必要时先编码。
- 不使用 `b23.tv` 等短链：短链有有效期，过期后可能指向错误页面。B 站视频用完整 `BV` 号。
- 页面名区分大小写与繁简；不确定时先搜索确认。

## 8. 文件与画廊

```
[[文件:示例.png|thumb|200px|left|alt=描述|说明文字]]
```

选项：

| 选项 | 作用 |
|---|---|
| `thumb` | 缩略图，带边框与说明 |
| `frame` | 原始尺寸边框图 |
| `left` / `right` / `center` / `none` | 对齐方式 |
| `200px` / `x200px` | 宽 / 高（像素） |
| `upright=0.8` | 按用户偏好缩放 |
| `alt=文字` | 替代文本 |
| `link=目标` | 点击跳转到指定页面 |
| `link=`（空） | 取消点击跳转 |
| 最后一段无等号文字 | 说明文字 |

画廊：

```
<gallery>
文件:A.png|说明A
文件:B.png|说明B
</gallery>
```

文件实际地址由标题哈希与内容哈希决定，不要手工拼接；用 `get-file` 或 `prop=imageinfo` 取。

## 9. 模板

| 用法 | 说明 |
|---|---|
| `{{模板名}}` | 调用模板 |
| `{{模板名\|参数=值}}` | 命名参数 |
| `{{模板名\|值}}` | 位置参数（`{{{1}}}`） |
| `{{{参数\|默认值}}}` | 模板内取参数并给默认值 |
| `{{subst:模板名}}` | 替换引用，保存时展开 |
| `{{msgnw:模板名}}` | 原样显示模板源码 |

包含控制：

| 标签 | 作用 |
|---|---|
| `<noinclude>…</noinclude>` | 只在模板页显示，不被引用 |
| `<includeonly>…</includeonly>` | 只在被引用时生效 |
| `<onlyinclude>…</onlyinclude>` | 只引用该范围内的内容 |

模板说明放在 `模板:名称/doc` 子页，用 `<noinclude>{{模板:名称/doc}}</noinclude>` 引入。

## 10. 解析器函数

| 函数 | 用途 |
|---|---|
| `#if:` | 非空判断 |
| `#ifeq:` | 字符串相等 |
| `#switch:` | 多分支 |
| `#expr:` | 算术表达式 |
| `#ifexpr:` | 表达式条件 |
| `#ifexist:` | 页面存在性 |
| `#time:` | 时间格式化 |
| `#tag:` | 生成 HTML 标签，如 `{{#tag:ref\|内容\|name=x}}` |
| `#arraymap:` | 按分隔符遍历（Arrays 扩展） |
| `#vardefine:` / `#varexists:` | 页面级变量 |
| `#css:` | 注入 CSS |
| `#widget:` | 调用 Widget |
| `#ask:` | SMW 查询 |

约束：

- 高开销函数单页上限 **100 次**，超出后恒返回「不存在时的值」，并进入 `分类:有过多高开销解析器函数调用的页面`。
- 检查特殊页面、跨 wiki、命中查询缓存不计入；同一目标重复检查只计一次。
- 预览页底部「解析器分析数据」显示各函数调用次数与耗时。
- 大量条件分支改用 Lua 模块。

## 11. 引用

```
正文<ref name="src1">来源说明</ref>
再次引用<ref name="src1" />
== 参考资料 ==
<references/>
```

- 具名引用必须至少有一处带内容的定义，否则报「引用错误：无效 `<ref>` 标签」。
- 只写 `<ref name="src1" />` 而没有定义，同样报错。
- 分组引用：`<ref group="注">…</ref>`，输出用 `<references group="注"/>`。
- 参考资料节只放 `<references/>` 或对应模板，不重复抄条目。
- 引用内容写来源与版本/日期，便于核对。

## 12. 分类

- 加入：`[[分类:名称]]`；排序键：`[[分类:名称|键]]`。
- 全局排序键：`{{DEFAULTSORT:键}}`，放在分类之前。
- 隐藏分类：在分类页加 `__HIDDENCAT__`。
- 分类归属真实，分类页实体可能不存在，红链属正常。
- 判断页面归属用 `prop=categories`，不要用分类页是否存在判断。
- 模板用 `#arraymap` 等按字段生成分类时，改字段即改分类。
- 大批量改分类分批执行，避免进入处理队列。

## 13. 重定向

```
#REDIRECT [[目标页面]]
```

- 必须是页面第一行，之前不能有空格、注释或其它内容。
- 一个页面只保留一个重定向目标；双重重定向不会被跟随。
- 重定向页一般不写分类与正文。
- 移动页面时按需保留重定向，避免旧链接失效。

## 14. 行为开关

| 开关 | 作用 |
|---|---|
| `__NOTOC__` | 不显示目录 |
| `__FORCETOC__` | 强制显示目录 |
| `__TOC__` | 在当前位置插入目录 |
| `__NOEDITSECTION__` | 隐藏章节编辑链接 |
| `__NEWSECTIONLINK__` | 在「编辑」旁增加「新建章节」 |
| `__NOGALLERY__` | 分类页不显示文件缩略图 |
| `__HIDDENCAT__` | 本分类为隐藏分类 |
| `__NOINDEX__` | 不允许搜索引擎索引（视站点配置与权限） |

## 15. 转义与代码

| 需求 | 写法 |
|---|---|
| 显示 wiki 标记 | `<nowiki>[[不是链接]]</nowiki>` |
| 代码块（带高亮） | `<syntaxhighlight lang="python">…</syntaxhighlight>` |
| 预格式化文本 | `<pre>…</pre>` |
| 行内代码 | `<code>…</code>` |
| 注释（不输出） | `<!-- 注释 -->` |
| 表格内字面竖线 | `<nowiki>\|</nowiki>` |

`<code>` 只改变显示样式，不阻止内部标记解析；需要阻止解析时套 `<nowiki>`。

## 16. HTML 使用边界

- 允许使用经 Sanitizer 过滤的常见标签：`div`、`span`、`br`、`hr`、`p`、`ul`、`ol`、`li`、`dl`、`dt`、`dd`、`blockquote`、`center`、`sub`、`sup`、`small`、`s` 等。
- `class`、`id`、`style` 可用，但 `style` 会经过 CSS 清洗。
- `<script>`、`<style>`、`<iframe>` 在普通词条被禁止；需要时封装为 Widget。
- 布局优先用 wikitext 表格与模板；确需分栏时用站点已有的 Bootstrap 栅格类，而不是自建 `div` 结构。
- 不嵌套整页内容，不在内容区放大面积遮罩，不插入二维码。

## 17. 体积与性能

- 单页上限 **2 MB**（`maxarticlesize`）。
- 大表格拆分为子页面或改由模块生成。
- 首页避免重复调用含 `#css` / `<bstyle>` 的模板。
- 高开销解析函数按 §10 控制次数。
- 模板递归与深层嵌套会增加渲染开销，必要时改为模块。
