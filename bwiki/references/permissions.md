# 权限、用户组与特殊页面

## 前提

- 账号为 B 站统一账号：首次访问某站自动建号，用户名为 B 站 UID。
- **权限按站点独立**：每个站点是独立 MediaWiki 实例，A 站管理员在 B 站无权限。
- B 站等级 ≥2 且账号注册 >7 天，首次访问自动获得 `bilibili`；判定只在建号时进行一次。
- 编辑达到一定次数后自动获得 `自动确认用户`；此后无法手动撤销，只能由 `特殊:滥用过滤器` 由系统撤销。
- 不属于任何管理组时，须完成 **3 次编辑**才能查看特殊页面。

## 用户组

| 用户组 | 授予内容 | 关键边界 |
|---|---|---|
| `bilibili` | 编辑页面、评论 | 基础组 |
| `自动确认用户` | 编辑「仅允许自动确认用户」保护级别的页面 | 自动获得 |
| `自动版主化用户` | 编辑**跳过审核** | 由行政员或管理员授予 |
| `版主` | `特殊:Moderation` 审稿 | 无界面权限 |
| `管理员` | 常规管理与编辑全权；**可编辑 Widget** | **不可**编辑全站及他人 CSS/JS |
| `界面管理员` | 全站 CSS/JS，及他人 CSS/JS | **不可**编辑 Widget |
| `小部件编辑者` | 仅 Widget | — |
| `行政员` | 更改任何用户的用户组 | **无编辑特权**；通常仅站长 |
| `监督员` | 删除/恢复页面特定版本与日志 | 用于编辑战、恶意编辑后隐藏 |
| `机器人` | API 使用上限提高（同管理员）；编辑标【机】，默认不进最近更改 | 无需单独账号 |
| `checkuser` | 用户查核 | 审核相关组 |
| SMW：`管理员（SMW）`、`监护人（SMW）`、`编辑（SMW）` | SMW 属性/概念维护 | 站点装了 SMW 才有意义 |

## 审核相关

- 触发：编辑内容**疑似**包含「特定词汇」。
- 效果：修改**只对编辑者自己可见**；他人与匿名访问仍看到旧版本；编辑者可继续编辑该页。
- 入口：`特殊:Moderation`，由 `版主` 或 `管理员` 批准。
- 绕过：`自动版主化用户`、`管理员`、`机器人`。
- 时机：通常立即入队，少数情况约一天；版主不 24×7 巡查。

## 常用特殊页面

| 页面 | 用途 | 所需 |
|---|---|---|
| `特殊:Moderation` | 审核队列 | 版主 / 管理员 |
| `特殊:用户权限` | 查看与更改用户组、设置终止时间 | 行政员（管理员仅可改 `自动版主化用户`） |
| `特殊:用户组权限` | 全部用户组的权限明细 | 登录 |
| `特殊:版本` | MediaWiki 版本与扩展 | 登录，且满足 3 次编辑门槛 |
| `特殊:滥用过滤器` | 过滤器规则，可撤销自动确认 | 管理员 |
| `特殊:小工具` | 已安装 Gadget、导出 | 管理员 |
| `特殊:文件列表` | 文件清单 | 登录 |
| `特殊:最近更改` | 全站变更 | 登录 |
| `特殊:链入页面` | 反向链接 | 登录 |
| 页面 `?action=purge` | 清解析器缓存 | 登录 |

## 授权操作

- 目标用户必须**至少登录访问过一次**该站，否则在 `特殊:用户权限` 中加载不到。
- 输入 B 站 UID（如 `12345678`）→ 加载用户组 → 勾选 → 保存。
- 重要用户组建议设置终止时间，避免长期不活跃的高权限账号。

## 写前自检

1. `whoami` 看 `groups`。
2. 目标站是否为当前 `wiki` 参数所指站点。
3. 操作是否需要界面权限（CSS/JS）、Widget 权限、保护或删除等管理权限。
4. 若刚登录、编辑量少，先确认已过 3 次编辑门槛再访问特殊页面。
